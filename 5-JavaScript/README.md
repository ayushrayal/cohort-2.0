# JavaScript Starter

This folder contains beginner JavaScript exercises started on 2025-10-23. The exercises now cover core basics: variables, data types, operators, conditionals, loops, strings, functions, arrays, and objects. This README was updated and merged with the completion notes (2025-11-14).

What you'll find (file-by-file):

- `1-BasicOfJS/`
	- `1-BasicOfJS.html` — hello world + basic variables and console.log examples used to test JS in the browser.
	- `2-DataTypeInJS.html` — examples and exercises demonstrating JavaScript data types.
	- `3-OperatorsInJS.html` — operator examples (arithmetic, assignment, comparison).
	- `3-BasicPractice.html` — short practice snippets that exercise the operators and simple expressions.
	- `4-Assignment.html` — short assignment problems and solutions.
	- `details.txt` and `Details2.txt` — small notes and observations taken while learning.

- `2-ConditionsInJS/`
	- `1-BasicofConditionalStatements.html` — examples of `if`, `if-else`, `else if`, and `switch` statements.
	- `2-PracticeOFCS.html` — practice problems to reinforce conditional logic.
	- `4-PracticeLevelup2.html` — extra conditional practice problems.

- `3-Loops/`
	- `1-BasicOfLoops.html` — examples of `while` loops, prompting user input, and simple loop patterns.
	- `2-PracticeOfLoops1.html`, `3-PracticeOfLoops3.html`, `4-PatternsPrinting.html`, `5-AssignmentOf1-Nov-2025.html` — extra practice & assignments
	- `6-LoopsNotes.txt` — detailed notes on loop types and patterns

- `4-Strings/`
	- `1-BasicOfString.html` — string basics and methods
	- `2-NotesOfStrin.txt` — notes for string methods and examples

- `5-FunctionsInJs/`
	- `1-BasicOfFunctions.html` — function declarations, parameters, return values and examples

- `6-Arrays/`
	- `1-BasicOfJS.html` — array basics examples
	- `2-ArrayAllNotes.txt` — consolidated notes on arrays

- `7-Objects/`
	- `1-BasicOfObjects.txt`, `2-QuestionOfObject.html`, `3-NotesOfObject.html` — object basics and practice

How to run
- Open any `.html` file in this folder in a browser (double-click or use a static server).
- For a local server (recommended):

PowerShell (from repo root):
```powershell
python -m http.server 8000
# or
npx http-server . -p 8000
```

Then open the exercise page URL (for example, `http://localhost:8000/5-JavaScript/1-BasicOfJS/1-BasicOfJS.html`).
