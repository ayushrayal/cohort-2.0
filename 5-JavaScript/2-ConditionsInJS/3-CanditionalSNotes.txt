1. CONDITIONALS DEFINITION
================================================================================

WHAT ARE CONDITIONALS?
Conditionals allow your program to make decisions and execute different code blocks based on conditions.

CONDITIONALS KYA HAIN?
Conditionals aapke program ko decisions lene ki capability dete hain - different conditions ke according different code run kar sakte hain.

REAL-LIFE ANALOGY:
Jaise traffic light - red light: stop, green light: go
Waise hi programming mein - condition true: code block A, condition false: code block B

TYPES OF CONDITIONALS:
1. if statement
2. if-else statement  
3. else-if ladder
4. switch-case statement
5. Ternary operator

================================================================================
2. if STATEMENT
================================================================================

DEFINITION:
The if statement executes a block of code if a specified condition is true.

if STATEMENT KYA HAI?
if statement code ka block execute karta hai agar specified condition true hai.

SYNTAX:
if (condition) {
    // code to execute if condition is true
}

EXAMPLES:
// Basic if statement
let age = 20;

if (age >= 18) {
    console.log("You are an adult");
}

// Multiple conditions
let temperature = 25;
let isSummer = true;

if (temperature > 30 && isSummer) {
    console.log("It's hot summer!");
}

REAL-WORLD EXAMPLE:
// User authentication
let isLoggedIn = true;
let hasPermission = true;

if (isLoggedIn && hasPermission) {
    console.log("Access granted to dashboard");
}

================================================================================
3. if-else STATEMENT
================================================================================

DEFINITION:
The if-else statement executes one block if condition is true, and another block if false.

if-else STATEMENT KYA HAI?
if-else statement ek block execute karta hai agar condition true hai, aur dusra block agar false hai.

SYNTAX:
if (condition) {
    // code if condition is true
} else {
    // code if condition is false
}

EXAMPLES:
// Basic if-else
let age = 16;

if (age >= 18) {
    console.log("You can vote");
} else {
    console.log("You cannot vote yet");
}

// Grade check
let marks = 75;

if (marks >= 50) {
    console.log("You passed!");
} else {
    console.log("You failed!");
}

REAL-WORLD EXAMPLE:
// Form validation
let username = "john_doe";
let password = "secret123";

if (username.length >= 3 && password.length >= 6) {
    console.log("Valid credentials");
} else {
    console.log("Invalid credentials");
}

4. else-if LADDER
================================================================================

DEFINITION:
The else-if ladder allows you to check multiple conditions in sequence.

else-if LADDER KYA HAI?
else-if ladder multiple conditions ko sequence mein check karne ki capability deta hai.

SYNTAX:
if (condition1) {
    // code if condition1 is true
} else if (condition2) {
    // code if condition2 is true
} else if (condition3) {
    // code if condition3 is true
} else {
    // code if all conditions are false
}

EXAMPLES:
// Grade system
let marks = 85;

if (marks >= 90) {
    console.log("Grade: A+");
} else if (marks >= 80) {
    console.log("Grade: A");
} else if (marks >= 70) {
    console.log("Grade: B");
} else if (marks >= 60) {
    console.log("Grade: C");
} else if (marks >= 50) {
    console.log("Grade: D");
} else {
    console.log("Grade: F");
}

// Temperature category
let temp = 25;

if (temp > 30) {
    console.log("Hot");
} else if (temp > 20) {
    console.log("Pleasant");
} else if (temp > 10) {
    console.log("Cool");
} else {
    console.log("Cold");
}

REAL-WORLD EXAMPLE:
// E-commerce discount system
let cartTotal = 2500;

if (cartTotal > 5000) {
    console.log("20% discount applied");
} else if (cartTotal > 3000) {
    console.log("15% discount applied");
} else if (cartTotal > 1000) {
    console.log("10% discount applied");
} else {
    console.log("No discount");
}

5. switch-case STATEMENT
================================================================================

DEFINITION:
The switch statement executes different code blocks based on different cases.

switch STATEMENT KYA HAI?
switch statement different cases ke according different code blocks execute karta hai.

SYNTAX:
switch (expression) {
    case value1:
        // code for value1
        break;
    case value2:
        // code for value2
        break;
    default:
        // code if no cases match
}

EXAMPLES:
// Day of week
let day = "Monday";

switch (day) {
    case "Monday":
        console.log("Start of work week");
        break;
    case "Friday":
        console.log("Weekend is coming!");
        break;
    case "Saturday":
    case "Sunday":
        console.log("Weekend!");
        break;
    default:
        console.log("Regular work day");
}

// Calculator
let operator = "+";
let a = 10, b = 5;
let result;

switch (operator) {
    case "+":
        result = a + b;
        break;
    case "-":
        result = a - b;
        break;
    case "*":
        result = a * b;
        break;
    case "/":
        result = b !== 0 ? a / b : "Cannot divide by zero";
        break;
    default:
        result = "Invalid operator";
}

console.log(result);

REAL-WORLD EXAMPLE:
// User role permissions
let userRole = "admin";

switch (userRole) {
    case "admin":
        console.log("Full access to all features");
        break;
    case "moderator":
        console.log("Can manage content and users");
        break;
    case "user":
        console.log("Can view and create content");
        break;
    case "guest":
        console.log("Can only view content");
        break;
    default:
        console.log("Invalid role");
}

6. TERNARY OPERATOR
================================================================================

DEFINITION:
The ternary operator is a shorthand for simple if-else statements.

TERNARY OPERATOR KYA HAI?
Ternary operator simple if-else statements ka shorthand version hai.

SYNTAX:
condition ? expressionIfTrue : expressionIfFalse

EXAMPLES:
// Basic ternary
let age = 20;
let message = age >= 18 ? "Adult" : "Minor";
console.log(message); // "Adult"

// Nested ternary
let score = 85;
let grade = score >= 90 ? "A" : 
            score >= 80 ? "B" : 
            score >= 70 ? "C" : "D";
console.log(grade); // "B"

// Multiple operations
let isMember = true;
let discount = isMember ? 0.2 : 0;
let finalPrice = 100 * (1 - discount);
console.log(finalPrice); // 80

REAL-WORLD EXAMPLE:
// Login status
let isLoggedIn = true;
let userName = "John";

let welcomeMessage = isLoggedIn ? 
                    `Welcome back, ${userName}!` : 
                    "Please log in to continue";

console.log(welcomeMessage);

7. NESTED CONDITIONALS
================================================================================

DEFINITION:
Nested conditionals are conditionals inside other conditionals.

NESTED CONDITIONALS KYA HAIN?
Nested conditionals dusre conditionals ke andar conditionals hote hain.

EXAMPLES:
// User access control
let isLoggedIn = true;
let userRole = "admin";
let has2FA = true;

if (isLoggedIn) {
    if (userRole === "admin") {
        if (has2FA) {
            console.log("Full admin access granted");
        } else {
            console.log("Please enable 2FA for admin access");
        }
    } else {
        console.log("Regular user access");
    }
} else {
    console.log("Please log in first");
}

// Better approach with logical operators
if (isLoggedIn && userRole === "admin" && has2FA) {
    console.log("Full admin access granted");
} else if (isLoggedIn && userRole === "admin") {
    console.log("Please enable 2FA for admin access");
} else if (isLoggedIn) {
    console.log("Regular user access");
} else {
    console.log("Please log in first");
}

8. COMMON PITFALLS & BEST PRACTICES
================================================================================

COMMON MISTAKES:
1. Using = instead of == or ===
2. Forgetting break in switch cases
3. Deep nesting (pyramid of doom)
4. Not handling all possible cases

BEST PRACTICES:
1. Use === instead of ==
2. Keep conditions simple and readable
3. Use early returns to avoid nesting
4. Add default case in switch
5. Use descriptive condition names

EXAMPLE OF BAD CODE:
// ❌ Deep nesting (pyramid of doom)
if (user) {
    if (user.isActive) {
        if (user.hasPermission) {
            if (user.isVerified) {
                // main logic buried deep
            }
        }
    }
}

EXAMPLE OF GOOD CODE:
// ✅ Early returns (flat structure)
if (!user) return "User not found";
if (!user.isActive) return "User is inactive";
if (!user.hasPermission) return "No permission";
if (!user.isVerified) return "User not verified";

// Main logic - clean and visible
console.log("Access granted");
