CSS background-clip Property

Learn how to control where backgrounds are displayed

What is background-clip?

The background-clip property determines the painting area of the background - it defines whether the background extends under the border, padding, or is restricted to just the content area.

.element {
  background-clip: border-box | padding-box | content-box | text;
}

Visual Examples

border-box (default)
Background extends under border
padding-box
Background stops at border
content-box
Background only in content area

Text Clipping (Creative Effect)

BACKGROUND-CLIP: TEXT
.text-element {
  background: linear-gradient(45deg, #ff6b6b, #4ecdc4);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}
Note: For text clipping, you need to use -webkit-background-clip: text for better browser support and set color: transparent.

Property Values Comparison

Value Description Visual Area
border-box Background extends to the outside edge of the border (default) Border + Padding + Content
padding-box Background extends to the outside edge of the padding Padding + Content
content-box Background is painted within the content box only Content only
text Background is clipped to the foreground text (requires -webkit- prefix) Text shape only

  • Text effects: Create gradient or image-filled text
